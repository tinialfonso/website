# Valentina Alfonso — Personal Portfolio

Personal portfolio site for Valentina Alfonso, Product Manager at Scalestack.

## Live Site

[https://tinialfonso.github.io/website/](https://tinialfonso.github.io/website/)

## About

A single-page portfolio showcasing experience, case studies, and influences. Built with a warm, sun-toned visual identity featuring interactive cursor effects, scroll-triggered animations, and horizontal story overlays for case studies.

## Tech Stack

- **HTML** — Single-page structure
- **Tailwind CSS** (CDN) — Utility-first styling
- **Vanilla JavaScript** — Cursor effects, scroll reveals, tilt cards, magnetic buttons
- **Google Fonts** — Outfit (headlines) + DM Sans (body)
- **Material Symbols** — Icon set

## Features

- Custom cursor with footstep trail and step counter
- Cursor-following gradient glow blobs
- Scroll-triggered reveal animations (up, left, right, scale)
- 3D tilt cards and magnetic buttons
- Horizontal story overlay for case studies (keyboard navigable)
- CSS grain texture overlay
- Responsive design with mobile fallbacks
- Reduced motion support

## Sections

1. **Hero** — Introduction and CTA
2. **About** — Background and skills
3. **Experience** — Career timeline
4. **Case Studies** — Interactive project stories (tekuoia, TECHO, Zamba, Manos Felices)
5. **Library** — Books, podcasts, and articles
6. **Contact** — Email and phone
